# 产品规格 — 大乐透实验室

## 信息架构
前端一级入口建议：`彩票实验室 > 大乐透`（实际导航按策维现有布局适配）。

### Tab 1：模型选号
输入：
- 目标期号
- 历史截止期（默认目标期上一期）
- 历史窗口：全历史 / 最近N期 / 自定义期号范围
- 候选池规模：前区5..35、后区2..12（默认先形成中等候选池再组合）
- 输出注数/Top K
- 模型参数（高级设置）

输出：
- 候选组合列表
- 前区/后区
- 综合分与分项分
- N0..N7
- N_ab 矩阵
- 历史最高碰撞
- 历史碰撞稀缺排序
- 奇偶、三区、和值、跨度、连号

### Tab 2：随机选号
- 单式随机 N 注
- 复式选择：前区数量/号码、后区数量/号码
- 胆拖选择：前区胆/拖、后区胆/拖
- 追加 on/off
- 倍数 1..99
- 显示展开后的基本注数、基础金额、追加金额、总金额

### Tab 3：预算套餐
“套餐”是程序的预算模板，不是新的彩票玩法。
- 预算
- 模板：分散单式 / 追加单式 / 小复式 / 胆拖 / 混合
- 号码来源：模型 / 纯随机 / 历史碰撞稀缺 / 混合
- 混合时可设置份额
- 目标：不超预算、减少多注重复、提高号码覆盖分散度

### Tab 4：历史碰撞
- 输入单组5+2或选择某次运行
- 展示 N_ab 6x3矩阵
- 展示 N_k（0..7）
- 批量运行展示 M_k、U_k、M_ab、U_ab
- 支持下载 CSV

### Tab 5：冻结复盘
- 运行列表：Draft / Frozen / Settled
- 冻结时生成版本号与 SHA-256
- Frozen 不允许编辑
- 开奖后填入实际开奖（或从已有数据命中目标期）并 settle
- 显示：每注命中、号码池覆盖、A/B/C 对照、累计表现

## A/B/C 对照
至少支持：
- A：综合历史碰撞模型
- B：历史碰撞稀缺/低碰撞模型
- C：纯随机同注数基线

公平要求：
- 同一目标期
- 同一历史截止期
- 同等注数或同等预算（由用户选择比较口径）
- 随机组保存 seed（实验复现），但生产“再随机”使用安全随机源

## 文案
允许：历史碰撞次数、遗漏、冷热趋势、结构频率、回测命中。
禁止：必中、提高中奖概率、下一期必出、冷号补偿等确定性表述。
