# 策维 v1.12.1 数据维护版

## 版本目标

v1.12.1 不增加选号模型，集中修复开奖数据可信度、浏览器数据恢复和本地数据库一致性。

## 数据修复

- 大乐透历史共 2902 期，最新为 `26084`，开奖日期为 2026-07-27。
- 双色球历史共 3482 期，最新为 `2026085`，开奖日期为 2026-07-26。
- 双色球 `2026083` 的开奖日期按中国福彩网官方记录纠正为 2026-07-21。
- 双色球从 2013 年开始的可用官方开奖日期已批量补齐。
- 更新任务优先使用官方接口，`78500.cn` 作为备用来源。

## 校验规则

- 每个号码必须在彩种合法范围内，同一区域不得重复。
- 期号不得重复，且必须按升序排列。
- 已知日期区段内不得出现空日期。
- 开奖日期必须严格递增，不得晚于当前日期，并符合固定开奖日。

## 本地数据一致性

本地启动会先用仓库中的 CSV 重建 SQLite 开奖表。该过程只替换开奖数据，不删除用户保存的推荐方案和复盘记录。

## 数据备份

页面顶部“数据备份”现在同时提供两种方式：

1. 单用户 Supabase 云同步。
2. 无需登录的 JSON 离线导出和恢复。

离线备份同时包含大乐透和双色球的已选方案，可用于更换浏览器、清理缓存前备份或云端不可用时恢复。
