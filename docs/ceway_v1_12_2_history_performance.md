# 策维 v1.12.2 完整历史与性能优化

## 完整日期

- 双色球 3482 期历史数据从 `2003001` 到 `2026085` 均包含开奖日期。
- 2003 至 2012 年日期来自彩宝贝公开年度归档；写入前逐期核对现有红球和蓝球号码。
- 年度列表遗漏的日期仅在相邻已核验日期和固定开奖日能够唯一确定时补齐。
- `2007041`、`2009028`、`2009145` 三期临时调期开奖使用明确例外日期，其余期次继续执行固定开奖日校验。

## 更新策略

- 日常更新仍优先读取中国福彩网官方接口，失败时回退到彩宝贝。
- 全量维护模式通过 `--source auto --all` 执行，才会读取早期年度归档。
- 全量回填后只要存在空日期、号码不一致、日期倒序或非法开奖日，任务就会失败且不发布。

## 前端性能

生产构建将 React、图表、Supabase 和图标依赖拆为独立缓存资源。主入口由约 521KB 降至约 101KB，所有 JavaScript 资源均低于 500KB，不再触发 Vite 大资源警告。
