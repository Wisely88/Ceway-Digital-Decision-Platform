# 策维 v1.12.5 预算闭环与交互优化

## 本版目标

把“可控制预算、可解释、可复盘”真正放进用户操作链路，同时缩短手机端页面长度。

## 已完成

- 选号工作台恢复可见的本期支出上限。
- 三种玩法同时生成时共享一个总预算，自动调整胆拖、复式和单式结构。
- 单独玩法超过预算时不允许生成，并明确提示超出金额。
- 生成结果显示批次总费用、总覆盖和风险结论。
- 每个方案提供可折叠的生成依据与决策说明。
- 高风险方案保存前二次确认，不采用无法继续操作的硬拦截。
- 历史数据拆分为走势与评分、开奖记录、策略验证三个页内视图。
- 号码评分、历史回测和行为分析正式接入页面。
- 公开版开奖记录使用完整历史总数进行分页。
- 手机端使用三栏模块导航和紧凑顶部操作区，消除导航横向截断。
- 套餐模拟标注规则日期、适用地区和终端确认要求。

## 预算规则

选择“三种同时生成”时，系统首先保证胆拖、复式和单式各有一个合法方案，再在用户填写的本期上限内尽量使用预算。若最低合法组合仍超出上限，页面显示最低所需金额，不生成超限方案。

单独生成智能推荐或随机号码时，系统尊重用户选择的结构；预计费用超过上限时，生成按钮不可用，用户需要减少号码池、注数、倍数或关闭追加投注。

人工选号允许先生成结构点评；若方案超过预算或触发高风险提示，保存前必须再次确认，确保自选方案仍可进入复盘而不会被无提示丢失。
