# 策维 v1.12.4 后区与蓝球走势分析

## 本版目标

补齐走势分析只有前区或红球、缺少大乐透后区和双色球蓝球视图的问题。

## 交互调整

- 走势分析标题区新增区域切换。
- 大乐透可切换“前区 / 后区”。
- 双色球可切换“红球 / 蓝球”。
- 统计窗口、最新期号和五个走势页签保持原位，不增加重复长页面。

## 分析指标

两个区域都支持：

- 冷热号与当前遗漏叠加图；
- 遗漏分布及综合评分；
- 奇偶结构分布；
- 大小结构分布；
- 和值走势与区间。双色球蓝球为单号码，因此显示为号码走势与区间。

大小划分口径：

- 大乐透前区：1-17 小，18-35 大；后区：1-6 小，7-12 大。
- 双色球红球：1-16 小，17-33 大；蓝球：1-8 小，9-16 大。

所有指标只描述所选统计窗口内的历史开奖，不代表未来中奖概率。
